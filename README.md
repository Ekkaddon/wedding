# Сайт-приглашение «Алексей & Вера»

Статичная страница по макету Figma. Сборки и сервера нет: браузеру хватает файлов из этой папки.

## Что где лежит

- `index.html` — тексты и разметка страницы.
- `style.css` — оформление. Размеры заданы в единицах макета (ширина 402), страница тянется от 320 до 430 px.
- `rsvp.js` — анкета гостя. Номер получателя ответов записан в `RECIPIENT` в начале файла.
- `img/`, `fonts/` — картинки из макета и шрифты Great Vibes и Open Sans (лицензия OFL).

## Посмотреть на своём компьютере

```bash
python3 -m http.server 8765
```

После этого страница открывается по адресу http://127.0.0.1:8765/. Двойной клик по `index.html` тоже работает.

## Выложить в интернет (GitHub Pages)

1. Создайте на github.com публичный репозиторий, например `wedding`.
2. Загрузите в него содержимое этой папки: кнопка «Add file → Upload files» или `git push`.
3. В репозитории откройте Settings → Pages, в поле Branch выберите `main` и папку `/ (root)`, нажмите Save.
4. Через одну-две минуты сайт откроется по адресу `https://<логин>.github.io/wedding/`.

## После публикации

- В `index.html` в строке `og:image` замените `img/hero.jpg` на полный адрес, например
  `https://<логин>.github.io/wedding/img/hero.jpg`. Без полного адреса Telegram и WhatsApp не покажут картинку в превью ссылки.
- Отправьте ссылку себе в Telegram и WhatsApp и откройте её с телефона.
- Заполните анкету и проверьте, что сообщение приходит Алексею в обоих мессенджерах.

## Что поменять при необходимости

- Ответы должны приходить другому человеку: поправьте номера в `RECIPIENT` в `rsvp.js`.
- Появился адрес Instagram: оберните иконку в `index.html` ссылкой по образцу соседних.
